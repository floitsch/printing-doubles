# Coonen Chapter 7 transcription

`coonen_complete.ocr.tex` is the Gemini-produced transcription supplied by
Florian Loitsch on 2026-08-04. Its source is a 27-page photographic scan of the
relevant dissertation material. It replaces an earlier incomplete Tesseract
experiment and has not yet completed equation-by-equation verification.

The working copies are deliberately ignored by Git. Until both the audit and a
separate publication decision are complete, the scan-derived text remains a
local transcription with possible errors, not a public critical edition.
The maintainer may provide a private copy on request; it is not distributed as
part of this repository or site.

The audit will:

1. remove the unrelated final page of Chapter 6 from the beginning;
2. match the transcribed page sequence to the photographed spreads;
3. compare Algorithms B, D, L, S, P, and Q line by line;
4. verify constants, inequalities, hexadecimal literals, powers, and table
   entries against the images;
5. compile the LaTeX with a clean TeX installation;
6. record every substantive correction in `corrections.md`.
